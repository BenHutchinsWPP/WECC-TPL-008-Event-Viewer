Data Credits

This viewer combines public benchmark event data, weather reanalysis data, open map software, and public map layers.

  • NERC TPL-008-1 Reliability Standard and TPL-008-1 Benchmark Temperature Events, April 2025.
  • Copernicus Climate Data Store ERA5 hourly data on single levels from 1940 to present. The results contain modified Copernicus Climate Change Service information.
  • WECC Balancing Authorities boundary layer.
  • MapLibre GL JS for map rendering and Chart.js for charts.
  • OpenStreetMap contributors for base map data, tiles, Nominatim for place search, and infrastructure data (transmission lines, substations, generators). Processed with OpenInfraMap tagging patterns.
  • Warranty: None! Use at your own risk. Weather data estimated. TPL-008 regions are approximated for display purposes. BA overlay is approximated for visual effect.
